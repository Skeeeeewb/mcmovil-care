# MCmovil Care — EV4 (DSY1105)

Proyecto académico de Desarrollo de Aplicaciones Móviles.

Objetivo: facilitar la consulta de equipos, el registro de solicitudes de servicio técnico y la decisión sobre cotizaciones, integrando un microservicio Spring Boot propio y una API externa de referencia.

Estado actual: entrega EV4 finalizada en `main`, tag `ev4-final`. Verificada con 14 pruebas del backend y 52 de la app, 0 fallos; APK release firmado y validado.
